1. LLM
   (1) 모델의 원리 이해
       - 주요 layer들의 의미, 동작 원리, 구성 방법, 활용 방법
       - 데이터의 입력부터 출력까지의 Tensor 타입 값의 주요 흐름
       - 모델에서 어떤 내용을 학습하는지, 그 학습에 필요한 작업들
   (2) 데이터 구성 원리 이해
       - 모델과 학습 또는 평가 의도에 맞게 데이터 구성하는 방법
2. RAG
   (1) RAG 구성 이해 및 활용
       - RAG의 구성 요소 및 주요 흐름, 그 활용 방법
   (2) 관련 Libray 활용
       - llama-index, mcp 등 RAG 관련 library들을 적절하게 사용
3. Data
   (1) 모델의 원리 이해
       - 모델의 구조, 구성 방법, 동작 원리 및 방법, 활용 방법
       - 데이터의 입력부터 출력까지 Tensor 타입 값의 주요 흐름
       - 모델의 결과와 정답을 이용하여 학습
   (2) 데이터 구성 원리 이해
       - 모델과 학습 또는 평가 의도에 맞게 데이터 구성
   (3) 관련 Library 활용
       - sklearn 등 실습에서 다뤘던 주요 library
       - 학습에 필요한 library를 목적에 맞게 사용
   (4) 평가 Metric 이해
       - 평가 Metric의 원리와 방법
4. Vision
   (1) 모델의 원리 이해
       - 모델의 주요 layer의 의미, 구성 방법, 동작 원리, 활용 방법
       - 모델의 결과와 정답을 이용하여 학습
   (2) 데이터 구성 원리 이해
       - 모델과 학습 또는 평가 의도에 맞게 데이터 구성
   (3) 관련 Library 활용
       - torchvision.transforms 등 이미지 데이터 변형하는 다양한 방법
   (4) 평가 Metric 이해
       - 평가 Metric의 원리와 방법
5. On-device
   (1) Quantization
       - 모델을 layer 단위에서 양자화/역양자화 하는 과정
   (2) Pruning
       - 가중치의 중요도를 판단하는 기준, 불필요한 연산을 제거하는 과정
   (3) Distillation
       - 지식증류의 원리, Teacher 모델의 예측값과 정답값을 활용해서 Student모델 학습
